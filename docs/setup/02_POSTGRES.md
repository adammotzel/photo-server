# PostgreSQL Database Setup

Run [scripts/database/setup_db.sh](../../scripts/database/setup_db.sh) to setup the database:

```bash
./scripts/database/setup_db.sh
```

Then run [scripts/database/setup_test_db.sh](../../scripts/database/setup_test_db.sh) to setup the test database:

```bash
./scripts/database/setup_test_db.sh
```

Both scripts are safe to re-run.

See [DATABASE.md](../architecture/DATABASE.md) for schemas and design notes.
